# Narration System Specification

## Human Narrator Mode

Narrator manually controls:

- phase progression
- pacing
- timing
- atmosphere

App supports:

- hidden information
- tracking
- action visibility

---

## App Narrator Mode

App controls:

- timers
- narration
- automatic progression

---

## Narrator Dashboard

Should display:

- players
- alive/dead status
- roles
- actions
- votes
- current phase

---

## Narrator Controls

- Start Night
- Wake Werewolves
- Wake Seer
- Wake Witch
- Start Discussion
- Start Voting
- Reveal Result
- End Game
